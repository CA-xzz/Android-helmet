# 管理端

后台服务同源提供 `/dashboard`。页面集中显示设备位置与轨迹、人员绑定、运行和网络状态、真实或模拟来源、电池百分比、电压、摄像头可用性、活动告警、呼叫和媒体归档。告警以独立地图标记显示。查看角色只读，调度、主管和管理员可执行告警处置、呼叫控制及实时视频连接。

页面首次手动连接时读取 `/v1/access-profile`，成功后在页面可见期间每 5 秒自动刷新，切到后台时停止请求，回到页面后立即恢复。自动刷新更新位置、轨迹、设备状态、呼叫和告警，声音已由操作员启用时对新呼叫或新告警播放提示。schema 2 身份模式以 Bearer 令牌对应的服务端主体覆盖并锁定操作员 ID 和角色，显示组织、有效设备范围和能力。ADMIN 还可查看仅限本组织的脱敏主体目录和权限拒绝审计。目录不返回令牌、令牌摘要或其他组织信息。更换令牌时页面立即停止自动刷新，并清除旧身份、目录、审计和先前组织的运行数据。开发单令牌模式继续使用手工操作员 ID 和角色，不提供主体目录。

媒体归档区按可访问设备和照片或视频类型筛选最近 100 条记录，显示时间、人员、尺寸、时长、事件和位置。预览请求使用认证头，不把令牌写入 URL。页面核对服务端声明长度、实际读取长度、MIME 和 ETag 摘要标识；预览超过 100 MiB 时拒绝在页面载入。关闭预览或更换令牌会取消读取并撤销临时 Blob URL。

文字广播区列出最近 100 条发送记录及 RECEIVED、PLAYING、PLAYED、FAILED 或 EXPIRED 回执。具备 `CONTROL_BROADCASTS` 能力的调度、主管和管理员可选择目标设备、文字、语言、优先级和有效期后发送；VIEWER 的发送表单由页面禁用，服务端同时返回 403。换令牌会清除旧组织的广播记录和未发送草稿。

语音消息区只在实际身份具有 `PLAY_VOICE_MESSAGES` 能力时请求列表，并继续应用消息 `allowedRoles`。播放器使用带认证头的流式请求，不把令牌写入 URL；页面要求 Content-Length，并核对声明与实际长度、MIME 和 ETag。单条页面播放上限为 25 MiB。关闭播放器或更换令牌会取消读取并撤销临时 Blob URL；服务端把内容请求记录为 PLAYBACK 审计。

地图使用 Web Mercator 瓦片坐标。底图地址、署名和缩放范围由后台提供，未配置底图时仍按真实投影绘制坐标、轨迹和告警，不使用相对坐标替代。联调环境配置：

```sh
export HELMET_MAP_TILE_URL_TEMPLATE='https://地图服务/{z}/{x}/{y}.png'
export HELMET_MAP_ATTRIBUTION='地图数据与服务提供方署名'
export HELMET_MAP_MIN_ZOOM=3
export HELMET_MAP_MAX_ZOOM=19
```

模板必须使用 HTTPS，并同时包含 `{z}`、`{x}` 和 `{y}`。地图服务许可、调用限额和密钥注入由部署方确认，仓库不保存地图密钥。

实时视频入口以每页最多 100 条按序读取设备提交的 WebRTC OFFER，获取短期 ICE 配置，提交 ANSWER 和 ICE candidate，并播放远端视频轨道。VIEWER 不显示连接入口。H618 与同源浏览器已验证 Offer、Answer 和 ICE 信令闭环，但开发板没有摄像头且 ICE 未完成连接。真实媒体仍需外部 STUN/TURN、摄像头、网络和远端浏览器完成端到端验收。

令牌只保存在页面内存，不写入 URL、Cookie、localStorage 或 sessionStorage。权限中心只展示现有 schema 2 配置，不提供令牌签发、撤销或运行时权限修改。外部环境必须通过 HTTPS 访问。
