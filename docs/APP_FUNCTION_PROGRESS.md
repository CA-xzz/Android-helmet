## 2026-08-15 板端界面改造

### 实现结果

- 主界面已改为面向现场人员的横屏状态中心，包含设备总览、安全报警、功能状态、设备检测、维护信息和 debug 构建专用调试页。首页使用中文状态卡片展示总体状态、前台服务、网络、服务器、UART、定位、主要外设、活动报警、待上传队列、设备编号、应用版本和设备时间。
- UI 通过只读状态仓库组合前台服务状态、Room 告警和队列、运行配置及系统能力，不直接持有 UART、摄像头、定位或传感器资源。Activity 关闭、重建及重新打开不会停止核心服务。

- 七项功能分别显示可用、运行中、离线可用、等待外设、配置不完整或故障，并提供中文说明。原始枚举、完整 JSON、令牌和详细日志未放入首页。
- 页面支持方向键和确认键，焦点使用白色粗边框。核心信息适配 H618 的 1280×720、160 dpi 横屏，并兼容 720p 和 1080p 横屏；首页不依赖滚动或滑动手势。
- 调试入口由构建变体控制，仅 debug 构建包含。所有调试动作均标记为“模拟”或“调试”，release 构建策略测试确认不显示入口。

### 7. 5.6 高度检测

- 生产链路：HSL `SENSOR_SAMPLE` 将模块海拔和气压保存在固定载荷中。本轮把有效状态拆分为海拔 bit2 `0x0004` 和气压 bit4 `0x0010`；硬件网关只映射已置位字段。旧模块的 bit2 继续表示海拔，气压模块可独立进入生产换算路径。样本引用、模块单调时间、有效位、原始气压和原始海拔均写入 Room。
- 高度计算：直接海拔使用模块提供的毫米值；气压输入按标准大气公式换算为毫米高度。两种输入均先建立连续稳定基线，再计算相对高度和变化率。无有效高度字段的样本返回空输入源和空相对高度，但保留已校准基线等待后续有效样本，不把零值当成测量。
- 风险状态：配置提供高度阈值、迟滞、确认样本数和最短持续时间。孤立突变不能触发报警；持续超过阈值后进入 `HIGH` 风险，回到阈值减迟滞的安全范围后解除。稳定低速变化可按配置慢速修正基线。默认数值是工程测试值，不代表正式安全高度。
- 输入切换和故障：海拔与气压源切换时先解除活动风险，再为新来源重新校准。压力和换算高度越界时解除高度输出并发布一次传感器故障；有效输入恢复后清除故障并重新校准。候选样本计数达到配置值后饱和，长持续时间候选可跨检查点恢复；语义不可能的高度检查点会被拒绝并进入既有隔离恢复流程。
- 模拟隔离：debug 高度按钮改为 10 条稳定气压基线样本和 3 条风险气压样本，全部带模拟标记并经过正式检测、持久化和上传流程，不再直接构造高度报警，也不填充伪造海拔值。
- 本地输出：活动高度报警请求中文语音、LED 和振动。HSL `SET_OUTPUT` 的动作掩码为 bit0 与 bit1，解除命令使用相同掩码和请求标识；不再附加蜂鸣位。Android 振动器缺失时明确记录不可用，语音请求和风险记录继续执行。外部 LED 或单个执行器失败由可靠命令恢复队列重试，不阻塞告警持久化。
- 数据记录：高度事件复用安全告警记录，保存时间、风险状态、原始值、输入来源、相对高度、基线、变化率、阈值身份以及有效位置；无可信位置记录 `NO_FIX`。本轮没有新增高度分析平台或展示范围。
