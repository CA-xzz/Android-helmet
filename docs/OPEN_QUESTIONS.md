# 外部依赖

以下项目需要硬件、接线或现场参数，不能由仓库代码代替。

| 项目 | 所需输入 | 验证方法 |
|---|---|---|
| 摄像头 | UVC 或 Camera2 可见设备 | 枚举、拍照、1080p 录像、WebRTC 视频 |
| 音频 | 非静音麦克风和扬声器 | PCM 非零采集、回放、语音消息和通话 |
| GNSS/RTK | NMEA/RTCM3 模块、天线和差分源 | 定位质量、轨迹、围栏和 RTK 状态 |
| LoRa 对讲 | 厂商语音模块和载荷规范 | 建链、对讲、音量、断线恢复 |
| IMU | 采样率、量程和安装方向 | 跌落、冲击、晃动标定 |
| 近电 | 传感器量程和现场标定 | 距离分级、误报和恢复 |
| 高度 | 气压或高度传感器 | 基线、阈值、漂移和恢复 |
| 电池 | 可读电量计或 Android 电源节点 | 20%、10%、5% 阈值提示 |
| UART | 电平、地线、节点和波特率 | HSL 收发、重连、错误帧和按键 |

公网 WebRTC 还需要部署方提供 STUN/TURN、TLS 和网络策略。这些参数不写入仓库。
