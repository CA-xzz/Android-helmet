H618 HTTP 设备命令自动轮询验证

日期：2026-08-11（Asia/Shanghai）
设备：QUAD-CORE H618 p1
ADB 序列号：2c001031774186e21d3
Android：12，API 31
APK SHA-256：b8e9ad95ebaaafe7baafd872d5a1e1cd714c5c839f2290e6e34201f61430d345

目的

验证未配置 MQTT 时，前台服务能自动轮询 HTTP 设备命令。测试不直接调用 CommunicationWorker。

环境

- Android 当前没有默认网络，dumpsys connectivity 输出 Active default network: none。
- 主机后台监听 http://127.0.0.1:18080，通过 adb reverse tcp:18080 tcp:18080 接入。
- 本地回环任务不要求 Android 网络约束；远端后台仍要求已连接网络。

命令

./gradlew --no-daemon --quiet :device-android:app:connectedDebugAndroidTest -Pandroid.testInstrumentationRunnerArguments.class=com.example.helmet.HttpCommandPollingInstrumentedTest

结果

- HttpCommandPollingInstrumentedTest：1 项通过，0 失败，0 错误。
- foregroundServiceAutomaticallyAppliesHttpBroadcastCommand：通过，测试用例耗时 6.423 秒。
- 后台创建 TEXT_BROADCAST 命令后，设备自动执行 GET /v1/device-commands。
- 命令 93cb6763-b2d3-42bf-85f0-c1e0202c3d3c 状态为 ACKED。
- 广播 automatic-http-ac5e242a-ca68-4aab-b545-b3449c01fd99 收到 RECEIVED、PLAYING 和 FAILED 回执。
- FAILED 原因为 TTS_UNAVAILABLE。开发板没有可用 TTS，因此本记录不证明扬声器播放。
- 最终 APK 覆盖安装成功，冷启动后 HelmetService 的 isForeground=true。

结论

ADB 回环条件下，HTTP 后备通道可在前台服务运行期间自动获取设备命令、执行文字广播、提交播放回执和命令确认。该结果证明软件闭环，不替代真实 4G/5G、远端 HTTPS、MQTT、扬声器或弱网验收。
