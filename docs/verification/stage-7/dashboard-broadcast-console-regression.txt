阶段 7 管理端文字广播回归
日期：2026-08-11

实现范围

1. 新增 GET /v1/broadcasts，支持可选 deviceId 和 1..100 limit，按创建时间与 broadcastId 确定性倒序。
2. 列表返回文字、语言、优先级、有效期、最后状态和按设备发生时间排序的全部播放回执。
3. 列表沿用生产主体、组织和设备子集授权；跨组织设备筛选返回 403。
4. DISPATCHER、SUPERVISOR 和 ADMIN 新增 CONTROL_BROADCASTS 能力。VIEWER 可读取记录但不能发送，服务端写入返回 403。
5. 首条回执必须为 RECEIVED 且晚于广播创建时间，后续发生时间必须严格递增；PLAYED、FAILED 或 EXPIRED 终态后的状态回退被拒绝。
6. 管理端可选择目标设备、文字、语言、普通或紧急优先级和有效期，发送后显示设备接收、播放或失败时间线。
7. 更换令牌会清除旧组织广播列表和未发送文字草稿。
8. Android 广播处理以服务器命令创建时间作为首条回执下限，并以每条已保存回执作为下一条时间下限；设备未完成服务器授时时也不会生成早于广播创建的时间线。

证据边界

本记录新增本地浏览器、schema 2 身份、SQLite 后台、ADB reverse 和 H618 Android Worker 的完整软件链证据。浏览器与后台运行在同一开发主机，不是独立远端管理环境；Android 使用 HTTP 回环传输，不是生产 MQTT。H618 返回 `TTS_UNAVAILABLE`，没有形成扬声器输出、录音或声学可懂度证据。正式身份、真实双向 TLS Broker、生产网络、TTS 引擎和远端端到端验收仍未取得。
