目的

验证前台服务能在没有 Android 默认网络的 H618 上，通过 ADB 回环自动上报启动状态、已配置人员编号、服务器校时状态和 60 秒心跳。测试不直接创建或调用 DeviceStatusWorker。

环境

- Android 状态为 Active default network: none。
- 本地后台监听 http://127.0.0.1:18082，通过 adb reverse tcp:18082 tcp:18082 接入。
- 精确回环地址不要求 WorkManager 网络约束；远端后台地址仍要求已连接网络。

命令

./gradlew --no-daemon --quiet :device-android:app:connectedDebugAndroidTest -Pandroid.testInstrumentationRunnerArguments.class=com.example.helmet.StatusHeartbeatInstrumentedTest

结果

- StatusHeartbeatInstrumentedTest：1 项通过，0 失败，0 错误。
- serviceRepublishesServerTimeAndMaintainsPeriodicContact：通过，测试用例耗时 73.670 秒。
- 后台收到状态序号 25 至 28，设备 ID 为 6309dc08-d3c5-4a80-bb0e-e80d2a6d9af8。
- 序号 25 和 26 使用 SYSTEM 时间；收到服务器回执后，序号 27 使用 SERVER 时间，synchronized=true。
- 序号 28 在序号 27 后 59,466 毫秒到达，使用 SERVER 时间，synchronized=true。
- 四条状态均报告 personId=person-board-heartbeat、operationalState=OFFLINE_READY、networkState=UNAVAILABLE、simulated=true。
- 状态中 cameraAvailable=false、battery.present=false、location.fixType=NO_FIX，与当前开发板能力一致。
- 本轮 APK 覆盖安装成功，冷启动后 HelmetService 的 isForeground=true。
- 测试结束后移除 ADB reverse 和仪器测试包，重新安装主 APK；开发板只保留 `com.example.helmet`，HelmetService 以前台状态运行，PID 为 19668，最近 400 行日志无 FATAL EXCEPTION 或应用 ANR。

结论

前台服务在 ADB 回环条件下能自动完成启动状态上报、人员绑定传输、服务器时间校准后的重新上报和周期心跳，不依赖测试直接运行 Worker。相同人员编号由相机控制器写入拍照和录像元数据；当前开发板没有摄像头，不能取得真实媒体组合证据。相同约束选择同时用于轨迹、媒体和安全告警 Worker。该结果证明软件路径，不替代真实移动网络、GNSS、电池、摄像头或长时间在线验收。
